# Scope Demo

Demo ini ditujukan untuk validasi **UI, navigasi, struktur modul, dan model data awal** bersama koperasi.

Yang sudah aktif: baca data MySQL, dashboard, member 360, daftar simpanan/pinjaman, jurnal demo, pencarian tabel sederhana, dan input transaksi kasir.

Yang sengaja belum diotomatisasi: perubahan saldo setelah transaksi teller, amortisasi/bunga, posting jurnal transaksi baru, approval workflow, dan SHU final. Bagian tersebut sebaiknya dibuat setelah SOP dan contoh transaksi riil koperasi dikumpulkan agar engine akuntansi tidak dibangun berdasarkan asumsi.
