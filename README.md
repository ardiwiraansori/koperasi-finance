# Koperasi Finance

Web application untuk pengelolaan keuangan koperasi berbasis Laravel.

Aplikasi dirancang untuk menangani proses utama koperasi seperti:

- Keanggotaan
- Simpanan
- Pinjaman
- Kasir / Teller
- Kas & Bank
- Akuntansi
- Jurnal Umum
- Approval
- SHU
- Laporan Keuangan
- Audit Trail

> Project saat ini masih dalam tahap pengembangan / prototype.

---

# Technology Stack

Project menggunakan:

- Laravel 13
- PHP >= 8.3
- MySQL / MariaDB
- Blade Template
- HTML / CSS / JavaScript
- Composer
- Laravel Herd
- Git / GitHub

Environment development utama:

- Windows 10
- Laravel Herd
- Visual Studio Code
- MySQL
- DBeaver
- GitHub Desktop
